1

종합 주행 분석

속도, 엔진, 기어, 조향과 페달 입력을 한 화면에서 비교합니다.

차량 상태

  • FL·RL·RR 휠 속도 비교
  • 엔진 RPM과 기어 변화 확인
  • 스로틀과 브레이크가 겹치는 구간 확인

조향 그래프

  • Yaw와 횡G 버튼을 눌러 선을 켜거나 끕니다.
  • 핸들 옆 톱니를 눌러 영점·반전·조향 Y축 범위를 설정합니다.
  • 조향 Y축 설정은 표시 범위만 바꾸며 실제 조향각 값은 바꾸지 않습니다.
2

입력 및 서스펜션 분석

운전자 입력과 네 바퀴의 서스펜션 움직임을 비교합니다.

입력 분석

스로틀·브레이크·조향 그래프의 세로 커서는 같은 시점을 나타냅니다. 코너 진입과 탈출에서 입력 순서를 비교할 수 있습니다.

서스펜션 보정

  1. FL·FR·RL·RR 제목 옆 톱니를 누릅니다.
  2. 바퀴별 오프셋을 mm 단위로 입력합니다.
  3. 표시값은 raw × 고정 계수 + 오프셋으로 계산됩니다.

보정값은 이 브라우저에 저장되며 원본 CSV는 변경되지 않습니다.

3

GPS + IMU 주행 분석

실제 주행 위치와 차량 움직임을 같은 시각으로 재생합니다.

재생과 IMU

  • 재생 또는 Space로 시작·정지합니다.
  • 배속은 0.5×, 1×, 2×, 4× 중 선택합니다.
  • IMU LPF는 끄거나 5 Hz·20 Hz 중 선택합니다.
  • X·Y·Z 축 버튼으로 필요한 IMU 선만 표시합니다.

GPS 전체화면

  • GPS 전체화면을 누르면 지도 중심 분석 화면이 열립니다.
  • 상세정보를 켜면 속도·RPM·기어·조향·페달 그래프가 표시됩니다.
  • 재생 중 지도와 상세 그래프 커서는 같은 시점으로 움직입니다.

피니시 라인과 랩 계산

1피니시 라인 설정2지도에서 라인 양 끝 클릭3자동 계산된 LAP 확인4원하는 LAP 선택·비교
  • 라인은 차량 경로가 실제로 통과하도록 트랙 폭을 가로질러 그립니다.
  • 랩을 한 번 누르면 해당 랩만 표시되고, 여러 랩을 누르면 경로와 데이터를 겹쳐 비교합니다.
  • 랩 상세의 시작 지점·종료 지점 버튼은 재생을 멈추고 해당 시점으로 이동합니다.
  • 별표가 붙은 LAP이 베스트 랩입니다.

시간축·거리축 전환

  • 시간 s는 센서가 기록된 원래 시각으로 표시합니다.
  • 거리 m는 각 랩을 0~862.556m 공통 대표 경로에 맞춰 표시합니다.
  • 드라이버별 브레이크·조향·액셀 위치 비교에는 거리축을 사용합니다.

체크포인트·핸들링

  • 체크포인트를 통과 순서대로 추가하면 랩별 구간 기록, 통과·최저속도와 페달 시점을 비교합니다.
  • 핸들링 분석은 기본 OFF이며 버튼을 켰을 때만 계산합니다.
  • 언더·오버 표시는 슬립각 센서가 없는 추정값이므로 추정 점수와 지속시간을 함께 확인합니다.
▶

GoPro·YouTube 영상 동기화

GPS 전체화면에서 영상과 텔레메트리를 함께 재생합니다.

LOCAL MP4

GoPro 원본 파일

  1. CSV를 먼저 엽니다.
  2. GPS 전체화면에서 GoPro MP4를 누릅니다.
  3. 원본 MP4를 선택합니다.
  4. 영상 내부 시작 시각과 CSV 시간이 겹치면 자동 연결됩니다.

파일의 수정일이 아니라 MP4 내부 시작 시각을 사용합니다.

YOUTUBE

YouTube 영상

  1. 영상을 공개 또는 일부 공개로 업로드합니다.
  2. 설명에 아래의 시작 시각 한 줄을 넣습니다. 제목은 자유롭게 작성합니다.
  3. GPS 전체화면에서 YouTube를 누르고 링크를 붙여 넣습니다.
  4. 설명의 시각과 CSV 시간이 겹치면 자동 연결됩니다.
YouTube 설명 필수 한 줄NSSUR_START_KST=2026-08-11 15:13:24.000
YOUTUBE UPLOAD HELPER

영상 파일로 동기화 설명 만들기

GoPro MP4를 선택하면 영상 내부 시작 시각을 읽어 설명에 붙여 넣을 동기화 정보를 자동 생성합니다. 영상은 업로드되지 않고 이 브라우저에서만 확인합니다.

먼저 원본 MP4 파일을 선택하세요.

설명의 NSSUR_START_KST 한 줄은 반드시 그대로 사용하세요. 기존 설명이 있다면 이 한 줄만 추가하면 되고, 제목은 기존 방식대로 자유롭게 작성할 수 있습니다.

중요YouTube 영상의 앞부분을 자르거나 인트로를 추가하면 설명의 시작 시각과 실제 영상 0초가 달라져 동기화가 어긋납니다.
4

랩 구간 분석

선택한 한 랩의 모든 주요 채널을 같은 시간 또는 거리축에서 정밀하게 확인합니다.

7개 동기화 그래프

  • GPS·FL·RL·RR 속도
  • RPM·TPS, 기어, TPS·브레이크
  • 조향·Yaw rate, 종·횡G, 냉각수·유온
  • 제목의 채널 버튼으로 원하는 선만 켜거나 끕니다.

랩과 구간 선택

  • 오른쪽에서 랩과 START·CP·FINISH 구간을 선택합니다.
  • 재생 중 모든 그래프, G 원, 트랙 위치가 같은 시점으로 움직입니다.
  • 하단에서 선택 랩 범위 안의 구간을 직접 입력하거나 커서 막대로 이동합니다.

확대·이동

  • 휠은 주황색 커서선을 기준으로 확대·축소합니다.
  • 그래프를 클릭한 채 좌우로 드래그하면 커서와 표시 구간이 이동합니다.
  • ←→는 0.1초, Shift와 함께 누르면 0.01초 이동합니다.

거리축 비교

  • 거리 모드에서는 센서값을 공통 대표 경로상의 위치로 변환합니다.
  • 현재 중심선은 12개 정상 랩, 1m 간격 864점, 총 862.556m입니다.
  • 0.1m 표시는 보간 단위이며 GPS 절대 정확도가 10cm라는 뜻은 아닙니다.
5

드라이버·랩 비교

서로 다른 CSV의 랩을 같은 트랙 거리에서 직접 비교합니다.

CSV와 랩 선택

  1. 비교 CSV 추가로 한 개 이상의 세션 파일을 선택합니다.
  2. CSV 한 개를 열면 가장 빠른 두 랩이 자동 선택됩니다.
  3. 빠른 4랩 또는 베스트만으로 같은 세션의 랩을 빠르게 선택할 수 있습니다.
  4. 파일별 드라이버 이름도 직접 수정할 수 있습니다.

비교 결과

  • 속도, TPS·브레이크, 조향·Yaw, 누적 시간차를 공통 거리축으로 표시합니다.
  • 그래프에서 휠을 돌리면 마우스 위치를 기준으로 네 그래프가 함께 확대·축소되며, 더블클릭하면 전체 거리로 복원됩니다.
  • 주행선은 가공하지 않은 각 랩의 실제 GPS 경로이며, 재생하면 랩 색상의 커서가 같은 출발 시점부터 동시에 움직입니다.
  • 먼저 끝난 랩은 종료 지점에서 기다리며 스페이스바로도 재생·정지할 수 있습니다.
  • 체크포인트 표는 구간 기록·최저속도·제동 시작·재가속 위치·탈출 속도를 보여줍니다.
해석 기준첫 번째로 선택한 랩이 시간차 기준 랩입니다. 5Hz GPS 보간이므로 드라이버·랩 간 상대 비교에 사용하고 절대 위치를 10cm 정밀도로 해석하지 마십시오.
6

냉각 및 온도 분석

냉각수·유온·흡기온·ECU 온도의 변화와 최대값을 한 화면에서 확인합니다.

온도 상태 카드

현재 커서 시점의 네 가지 온도와 CSV 전체 구간의 최대 온도를 함께 표시합니다.

온도 추세 차트

냉각수·유온을 차량 속도와 비교하고, 흡기온·ECU 온도는 별도 차트에서 확인합니다. 그래프 제목 옆 색상 버튼으로 각 선을 개별 표시·숨김할 수 있으며, 하단 공통 타임라인과 확대·커서를 그대로 사용할 수 있습니다.

공통 거리축 측정 방식

랩과 드라이버의 데이터를 같은 트랙 위치에서 비교하기 위한 계산 기준입니다.

대표 경로862.556 m
기준점864개 · 약 1m
기준 랩정상 랩 12개
GPS5 Hz · 약 0.2초

1. 대표 경로 생성

유효 GPS 추출→피니시 통과로 랩 분리→거리 이상 랩 제외→12개 랩 위치 중앙값→1m 간격 재구성

각 랩을 누적 진행률 0~100%로 맞추고 같은 진행률에서 12개 랩의 위도·경도 중앙값을 사용합니다. 따라서 물리적으로 측량한 트랙 중앙이 아니라 정상 랩들의 공통 대표 주행 경로입니다.

2. 현재 위치를 거리로 변환

각 랩의 GPS 위치를 가장 가까운 기준점으로 반올림하지 않고, 인접한 두 기준점이 만드는 선분에 수직 투영합니다.

A · 200mQ · 200.37mB · 201mP · 차량 GPS

투영점 Q가 200m와 201m 사이의 37% 위치라면 중심 거리는 200.37m입니다. 이전 위치 기준 뒤 약 5m·앞 약 35m만 검색하고, GPS 노이즈 때문에 계산값이 뒤로 가면 이전 거리를 유지합니다.

3. 5Hz GPS 사이의 보간

s(t) = s₁ + (s₂ − s₁) × (t − t₁) ÷ (t₂ − t₁)

예를 들어 12.000초에 300.2m, 12.200초에 306.6m라면 12.100초는 303.4m로 계산합니다. 브레이크·액셀·조향 센서값은 바꾸지 않고 센서가 기록된 시각만 이 시간-거리 표를 통해 거리축으로 변환합니다.

주요 오차 원인은 GPS 절대 위치 오차, 5Hz 갱신 간격, 센서와 GPS의 시간 지연, 코너 곡률, 운전자별 라인 차이입니다. 60km/h에서 시간축이 0.1초 어긋나면 약 1.67m 위치 차이가 생기므로 미세한 차이는 영상과 반복 랩으로 검증해야 합니다.
